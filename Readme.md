# ❤️ HealthPredict

### Healthcare Appointment No-Show Risk Prediction System

HealthPredict is a machine learning-based web application designed to estimate the likelihood that a patient may miss a scheduled healthcare appointment.

The project combines a trained machine learning model with an interactive web interface. Instead of presenting the prediction as a simple form, the application introduces the concept through a cinematic scrolling experience featuring a realistic heart animation before taking the user to the prediction interface.

---

## 📌 Project Overview

Missed healthcare appointments, commonly known as **no-shows**, can create several problems for hospitals and healthcare providers.

When patients do not attend their scheduled appointments:

- Medical resources may remain unused.
- Doctors and staff time can be wasted.
- Other patients may have to wait longer for appointments.
- Healthcare providers may face operational difficulties.
- Early intervention opportunities can be lost.

HealthPredict attempts to address this problem by estimating the probability of a patient missing an appointment.

The system analyzes information about the patient and appointment and produces:

- No-show probability
- Probability percentage
- Risk level
- Prediction result

For example:

Probability : 0.2291
Percentage  : 22.91%
Threshold   : 0.20
Prediction  : Potential No-show
